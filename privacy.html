Privacy policy

Last updated: 17 October 2026

Outreach is a private, self-hosted email tool used only by its owner. This policy explains what Google user data it accesses when the owner connects their own Gmail account, and what it does with that data.

Google data Outreach accesses

  • Your email address (userinfo.email), to identify which Gmail account is connected.
  • Sending email (gmail.send), to send the emails and follow-ups the owner writes and schedules.
  • Reading email metadata and messages (gmail.readonly), only to detect replies, automatic replies and delivery failures (bounces) to emails Outreach sent, so follow-ups stop automatically.
  • Reading Google Sheets (spreadsheets.readonly), only for a spreadsheet the owner chooses to import contacts from.

How the data is used and stored

  • Data is used only to provide these features to the owner. It is never sold, never used for advertising, and never shared with third parties.
  • Outreach stores the minimum it needs: the connected email address, an encrypted access token (AES-256-GCM), and, for emails it sent, the message and thread IDs, reply status and a short snippet of replies so the owner can see who answered.
  • Data is stored in the owner's own database. No one else operates or has access to it.
  • No humans read your data, except the owner viewing their own mailbox information in their own tool.

Google API Services User Data Policy

Outreach's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Recipients of emails

People who receive an email sent with Outreach can stop all further emails by using the unsubscribe link in the email, or by replying "unsubscribe". Their address is then added to a permanent do-not-contact list.

Removing access and deleting data

You can revoke Outreach's access at any time at myaccount.google.com/permissions. The owner can delete all stored data by deleting the Outreach database.
